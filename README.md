# 活字排版工坊

一个纯前端本地应用，包含两个视图：

- **排版工坊**：维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出 PNG 预览图。
- **生产订单**：创建订单（交期、纸张尺寸、横竖排、优先级、正文），系统按库存自动分配字模；缺字/缺量时给出补齐清单，可手工调整但不能超过可用量。版面落字、各未完成订单统一核算库存，任何订单都不能抢占他单或版面占用的字模；库存调整或字模移除后自动重核算所有未完成订单（高优先级优先保留），不会出现"显示充足却实际超用"。订单按 待排版 → 制作中 → 已完成 流转，已完成可返工；返工重新开工前会按当前库存重新核对，不足则停在返工并列出缺口，非法跳跃一律拦截，每次变更都有记录。已完成的订单自动释放字模回库存。

所有数据（字模、版面、草稿、订单、分配、流转记录）保存在 localStorage，刷新后仍在。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
